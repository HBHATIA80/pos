# Phase 1 implementation

This branch records the Phase 1 foundation implementation. The canonical development branch is `phase-1-foundation`.

## Scope
- Runnable Next.js application shell
- Responsive mobile/tablet/desktop baseline
- Supabase browser and server clients
- Supabase session middleware
- Foundation SQL migration for business identity, profiles, roles and audit logs
- RLS primitives and timestamp trigger
- Local setup documentation

## Not in Phase 1
- Signup/login UI
- Phone verification
- Products/categories/brands
- Parties
- Sales/purchases
- Receipts/payments
- Expenses
- Ledger
- Reports/P&L

Those are intentionally deferred to later phases.
